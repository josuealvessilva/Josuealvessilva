## `02` — Featured Project

### FlemingCore

**Inventory Intelligence Platform | FIAP Challenge Eurofarma 2026**

Plataforma voltada à gestão inteligente de estoques farmacêuticos, com foco em reduzir perdas por vencimento, identificar riscos e apoiar decisões relacionadas a lotes, validade e giro de medicamentos.

**Minha atuação: Cloud Project Engineer**

- Infraestrutura cloud baseada em Google Cloud e Firebase.
- Integração de serviços de backend com banco de dados gerenciado.
- Trabalho com autenticação e controle de acesso por perfil.
- Configuração e operação de serviços de infraestrutura, conforme as necessidades do projeto.
- Atenção à observabilidade, à gestão de segredos e à separação de ambientes.

**Stack principal:** Google Cloud · Firebase · PostgreSQL · Python

O projeto faz parte do FIAP Challenge Eurofarma 2026.
